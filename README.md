> **Arena of Coders — AI Anti-Cheat Subsystem** is an autonomous multi-modal verification suite designed to uphold academic and competitive integrity in hackathons and coding tournaments.

---

## 🌿 Specialized Model Branches

Each AI service in this repository is maintained in its own dedicated branch:

| Branch | Component | Description & Core Technologies |
| :--- | :--- | :--- |
| [**`modele-checkpoint`**](https://github.com/negzaoui16/Arena-Of-Coders-AI-AntiCheat/tree/modele-checkpoint) | **Visual AI & Biometrics** | Image analysis of workspace, developer environments, and facial validation using CLIP & DeepFace. |
| [**`modele-vocal`**](https://github.com/negzaoui16/Arena-Of-Coders-AI-AntiCheat/tree/modele-vocal) | **Acoustic AI** | Audio analysis classifying discussion topics (code, architecture vs distraction) using Whisper & mDeBERTa-v3. |
| [**`modele-cheat`**](https://github.com/negzaoui16/Arena-Of-Coders-AI-AntiCheat/tree/modele-cheat) | **Code Integrity AI** | Detection of copy-paste, plagiarism, and synthetic AI-generated code (ChatGPT, Copilot) using fine-tuned RoBERTa. |
